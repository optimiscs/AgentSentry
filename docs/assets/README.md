# 首页演示素材

[readme-events.jpg](readme-events.jpg) 为 2026-09-15 本地运行 AgentSentry `0.1.0.dev1` 的控制台截图，展示内置 Issue 演示的事件时间线。画面来自浏览器原始截图，未重新绘制或修改界面内容。

该演示由 [demo.py](../../src/agentsentry/demo.py) 提交预设候选动作，使用独立工作区和合成凭据，无模型调用。真实网关结果依次为读取 Issue 放行、读取合成私钥阻断、读取 README 放行。首页表格的写报告 ASK 来自另一组内置审批演示。

截图运行环境是本地 macOS；左下角 `5090` 为现有界面的历史环境标签，不代表本次运行主机或 GPU 使用情况。该图不用于证明模型防护效果或 Linux 代码执行沙箱验收。

复现：按 [使用指南](../getting-started.md) 启动服务并登录，点击 **Issue 注入**，滚动到事件时间线。部署参数、令牌和真实用户数据均未出现在截图中。
