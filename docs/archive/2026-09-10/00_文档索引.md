## 文档清单

| 文件 | 飞书页面标题 | 作用 |
|---|---|---|
| `01_AgentSentry_PRD.md` | 产品需求文档（PRD） | 定义业务目标、范围、优先级、用户场景与验收指标 |
| `02_AgentSentry_Threat_Model.md` | 威胁建模（Threat Model） | 定义资产、攻击者、信任边界、安全不变量与攻击链 |
| `03_AgentSentry_System_Design_RFC.md` | 系统设计 RFC | 冻结总体架构、控制流、技术决策、失败策略与 Rollout |
| `04_AgentSentry_API_Data_Schema.md` | API 与数据模型 | 冻结跨模块接口和 ContextChunk / IntentIR / ActionIR / Trace 等 Schema |
| `05_AgentSentry_Security_Policy_Spec.md` | 安全策略规范 | 定义 Policy DSL、规则优先级、ALLOW/ASK/BLOCK 与 Approval Scope |
| `06_AgentSentry_Evaluation_Plan.md` | 评测方案 | 定义公开 Benchmark、自建数据、Baseline、指标与 Ablation |
| `07_AgentSentry_Test_Plan.md` | 测试与验收计划 | 定义单测、集成、E2E、故障注入、CI Gate 与缺陷等级 |
| `08_AgentSentry_Deployment_Operations.md` | 部署与运维设计 | 定义部署、配置、审计、监控、故障处理与回滚 |

## 建议 Review 顺序

三人首先共同 Review **03 系统设计 RFC → 04 API 与数据模型 → 05 安全策略规范**，先冻结系统边界、跨模块契约和决策语义；随后依次 Review **01 PRD → 02 Threat Model → 06 Evaluation → 07 Test → 08 Deployment**。

## 文档状态约定

- **Draft**：允许结构性修改。
- **In Review**：进入设计评审，关键修改需记录决策。
- **Approved**：作为当前实现契约，破坏性变更需要升版本并重新 Review。
- **Deprecated**：已被新版替代，不再作为实现依据。
