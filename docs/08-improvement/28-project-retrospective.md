## 每次复盘输入

计划版本与backlog、实际完成/未完成项、RTM与测试报告、实际人日/算力/调用量、缺陷和回归记录、用户演示反馈、ADR变更及技术债。未测数据保留null，不能用计划值代替实际值。

| 维度 | 要回答的问题 | 输出 |
|---|---|---|
| 目标与范围 | 哪些FR/Gate有证据、哪些延期、原因是什么 | 计划/实际差异表，版本范围调整 |
| 协作接口 | Schema/Owner/依赖是否减少或产生返工 | 改进ADR、契约测试、负责人 |
| 安全与质量 | 是否有绕过、误拦或ASK负担被指标掩盖 | 按风险排序的回归与策略任务 |
| 研究效果 | 同配基线/消融支持哪些结论，哪些不支持 | 结论/证据/限制及下一实验 |
| 资源与成本 | 单卡排队、上下文、并发、费用是否符合估算 | 下一阶段容量与预算 |
| 交付体验 | 非作者能否接入/部署/解释一条风险 | 手册/界面/演示修订 |

## 记录模板

RETRO-ID、里程碑、日期、参与人；做得好的具体事及证据；阻碍/根因；不再做的内容；下阶段最多三项优先改进；每项Owner/截止/完成标准；需用户决定的范围或资源事项。

未过Gate仍可复盘并决定下一步，但不能把复盘会议当作验收。下次复盘首先检查上次改进是否真的完成。
