# ADR-009：精确动作合约的隔离候选实现

日期：2026-09-12。状态：候选实现已通过工程回归，未合并到活动服务和 v4 评测源码。Owner：工程开发；独立安全评审待完成。

## 问题与选择

仅按 FILE_WRITE 等副作用授权，不能区分写哪个文件、写入什么内容。同一用户任务中出现一个写动词，不应被解释为任意写操作都已得到精确授权。通用语义规划仍需要验证；本候选先实现可以确定解释的有限请求语法，并为后续受信规划提供动作约束原语。

实现保存在工程 `artifacts/development/semantic-contract-v1`，含起点哈希、差异补丁、独立测试及 Schema。当前 27B 批处理的四个作业会在启动时读取源码，因此不能运行到一半更新主目录；候选使用单独工作目录和 PYTHONPATH，测试临时状态也与活动网关分离。

## 合约语义

IntentIR 新增 `contract_mode` 和 `exact_action_grants`；ActionIR 新增 `task_binding_hash`。每个授权绑定服务器、工具、全部参数和副作用集合，并记录受信任务的字符区间。参数值不重复存入授权对象，仅保存哈希。这个哈希不是保密加密或抗字典攻击承诺。

支持带 JSON 双引号字面量的创建/写入文件、Python 执行、Git 提交消息和 HTTP POST 请求，以及有限中文同义表达。例如：

```text
Create file "notes.txt" with content "public"
POST "public" to URL "https://unknown.example.test/report"
请创建文件"notes.txt"，内容为"public"。
```

识别到精确命令开头后，如果引号、参数、附加条件、任一分句或数量限制不能完整解析，合约保持关闭，不退回宽泛写权限。未进入这套语法的普通任务继续使用既有 Effect 合约，不能声称已解决通用自然语言授权。文件字面路径须为无歧义的相对路径；实际文件操作继续经过边界、符号链接和版本检查。

`exact_mutations` 模式下，每个非读取动作都必须匹配一个授权，否则 ASK；静态权限上限、明确禁止及硬 BLOCK 始终优先。HTTP 只按适配器已有语义补默认 POST/空 body 和方法大小写，不丢弃未知参数，不扩大 URL。原有精确人工审批可以批准合约外的单次动作；完整 Intent/Action 快照仍参与审批签名。

子会话只能保留父、子合约授权的交集；改写子任务不能清除父级精确约束。授权目前不是一次性工作流步骤，不保证动作数量、执行顺序或引用对象语义。可重复执行的请求仍依赖原有幂等键/审批状态机，不能把该原语直接用于重复付款授权。

## 原生客户端与外部目录

原生 Hook 的整文件 `Write` 可映射到相同内容和相对目标的独立 `native-hook/native.Write` 授权。`Edit` 的替换片段与补丁文本不是整文件内容，不复用该授权。新适配器标签为 `native-posix-3-candidate`。测试涵盖 Codex/Claude Code 事件格式及 claim，网关没有代替客户端执行文件写入；这仍不是实际厂商 CLI 端到端验收。

AgentDojo/InjecAgent 的工具目录不等于 builtin 目录，候选运行器显式关闭这套 builtin 字面语法，避免将相似工具名称错误映射。当前候选没有产生公开 benchmark 改善证据，不会替换 v4 的分数。

## 替代方案与验证

继续只用 Effect 合约改动小，但保留工具/参数授权缺口。直接使用模型生成权限可覆盖更多表达，但会引入规划器、参数提取及不可信数据来源验证问题；当前不把未经验证的模型结果当授权。后续应在此原语上增加受信任务规划与来源绑定，单列适配协议并重新做配对评测。

候选完整回归 **192 passed**，其中新增32项；黄金回归 **20/20**；语句/分支覆盖率分别 **81.79%/70.51%**。生成 OpenAPI 与7个模型 Schema，F/I lint 通过。测试包括变工具/服务器/副作用/内容/目标、部分解析、非法转义、Unicode、父子权限交集、硬规则优先及原生 Edit 不可冒充 Write。[机器证据](../evidence/literal-contract-candidate.json)。

候选57个自研 Python 文件的50-token精确重复覆盖为0.69%，标识符归一为2.12%；精确重复覆盖 token 仍为352，与活动版本相同，比例变化主要来自新增代码，不能解释为又消除了重复。统计不含测试、生成JS和上游代码，也不是外部原创性或比赛查重认证。
