# ADR-011：ASB 本地适配与分离执行评分

日期：2026-09-12。状态：隔离适配器已通过工程回归，真实Agent模型小样已完成但未验收。Owner：评测工程；协议与安全独立评审未完成。

固定ASB提交 `1f561dccf92d55302368fa67679b4ba9d9c8fdc4`。原生Agent构造会初始化云服务依赖，原始记忆向量来自OpenAI嵌入；现有环境使用本地模型。原生成功判定还会匹配消息中的目标文字，即使没有相应工具执行也可能判成功。

候选 `artifacts/development/asb-local-v1` 对已核查的源文件做哈希校验，仅提取指定函数AST，保留原生规划循环、工作流注入、工具执行顺序、记忆查询和文本评分。拒绝哈希不一致的源码，不导入上游带初始化副作用的模块，不编译或执行攻击字符串。工具依照上游实现返回模拟文本，不访问真实网络、文件或凭据。

全部可见工具使用统一的目录适配，均映射为不透明的模拟状态写入；不按“攻击工具”评分标签建立黑名单。这只是ASB无实际参数语义工具的适配，不能冒充生产权限模型。原始用户任务与注入后的运行时文本明确分开，是本实验的协议变化。攻击目标和答案标签仅进入场景构造/评分，不进入授权。

记忆适配重建462条原文的E5向量，以原生任务与工具目录构成查询，精确余弦取top1；800个唯一查询预先冻结。没有混用原始1536维缓存与新768维向量，没有按攻击答案选择记忆。CPU准备耗时313.77秒，实际文档最大441 token、查询最大295 token，均未触及512上限。完整取回的原文仍交给原生工作流提取函数。此变化明确标记为本地E5适配，原始嵌入配置复现仍未完成。

报告并列记录原生文本ASR/效用与模拟工具实际分派ASR/正常工具执行覆盖。无效、缺失、规划失败保留为未知并计入保守上界。ASB mixed的执行ASR门槛仍为35%；正常工具覆盖不等于独立正常任务效用验收。与其他配置比较时校验完整源码、协议、检索和预算指纹。

替代方案是直接导入上游并使用原云服务，复现改动较少，但依赖当前未配置的外部模型/嵌入服务；替代为按攻击标签取回对应记忆会改变检索问题，未采用。

240项pytest、20条黄金回归、11个ASB模拟夹具和6个AgentDojo夹具通过。随后完成80条真实模型小样，结果及未知记录见[小样评审](../05-validation/asb-pilot-review.md)，不构成全量验收。共享结构化模型调用与现有运行器共用错误/延迟记录，未复制论文防御实现。[候选指纹](../evidence/asb-local-candidate.json)、[检索证据](../evidence/asb-local-retrieval.json)及[协议说明](../05-validation/asb-protocol-preparation.md)记录适用范围。
