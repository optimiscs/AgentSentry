# ADR-008：受信任务中的精确接收目标与共享评测执行层

日期：2026-09-12。状态：已实现并通过回归；公开 benchmark 效果待验收。

## 问题

原 Intent 模板漏掉 create/add/reserve 等英文授权表达，并将 runner/editor 等词中的子串误识别为执行/编辑授权。网络策略将用户已明确指定的完整目标与未知目标同样要求确认。正常任务效用明显下降；两个公开基准运行器也复制了模型 HTTP、清单与恢复逻辑。

## 决策

补全有限的任务动词语法并采用英文单词边界，明确否定优先。新增 IntentIR.authorized_destination_hashes 与 ActionIR.destination_hashes，字段默认空列表，兼容已有会话。目标哈希只由受信用户任务解析器和受信工具适配器构建，绑定完整 URL/接收方，而非域名、子串或正文地址。

策略谓词 `intent.destination_matches("destination")` 只有在外发已授权、没有明确禁止、实际目标集合非空且全部精确匹配时成立。目标自身仍为 UNKNOWN/UNTRUSTED，不修改来源或租户信任标签。硬 BLOCK、静态权限上限、敏感信息外发规则继续优先。未明确目标、额外 CC/BCC、参数类型不支持以及金融金额约束未实现时继续 ASK。

HTTP 重定向不会自动继承原 URL 授权，须提交目标 URL 作为新动作。该规则也防止同主机不同路径或端口自动获得权限。遇到重定向时，原请求已可能产生副作用，不允许将失败自动解释为可重试。

公开基准共享 `benchmarks/local_model.py` 的环回模型调用、模型配置、源码清单和恢复逻辑；保存原始失败输出。`support_files` 哈希进入配对检查，防止辅助模块变化后错误恢复旧运行。原生判定器及失败分母保留。

## 依据、代价与验证

[研究比较](../05-validation/research-baselines-2026-09-12.md)提供受信规划和能力约束的背景。本改动是有限语法与精确目标绑定，未实现 CaMeL、IPIGuard 或同名 AgentSentry 论文算法，不提供它们的安全保证。

新增 20 项测试覆盖明确授权/否定、子串误匹配、不可信上下文无法授予目标权限、完整目标匹配、额外接收方、秘密外发及同源重定向。完整工程检查为 160 passed，黄金回归 20/20。粗粒度副作用合约仍不能证明调用的金额、条件、数据内容符合任务，见技术债务与后续计划；正常效用和攻击效果必须通过真实配对评测验证。

授权模板进一步收紧为受支持的请求语句，并忽略引号中的示例：解释 delete、阅读 book、查询 reservation 不授予写权限。模板版本 templates-1.2；新增 5 个反例回归。未知表达保留 ASK。
