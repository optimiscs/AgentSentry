# ADR-007 · 5090 开发版的实际运行边界

日期：2026-09-12 ｜ 状态：implemented_for_development，待独立评审

## 背景与选择

5090 当前为 25 CPU 配额、90 GiB 内存、单 RTX 5090 32607 MiB 显存。宿主缺少 Docker，且 unshare 用户命名空间被拒绝；具备 Linux chroot、setuid/setgid 和 libseccomp。采用工程独立 Python 3.12.3 虚拟环境，应用代码要求 Python >=3.11；既有推荐 3.11 不再作为当前实测环境陈述。

FastAPI + Pydantic + SQLite 单进程承载网关。MCP 使用实际安装并锁定的 1.30.0（约束 <2），以官方 SDK 测试 stdio 与 Streamable HTTP；不是未验证的跨主版本兼容承诺。前端 React 19 / Vite 6.4.3 在本地 Node 22 构建，静态资源同步到 5090。Vite 初始版本经 npm 官方审计发现问题后升级；复查零已知漏洞不代表不存在未知风险。

## 执行与权限

同一状态目录由文件锁保证仅一个 Runtime，审批和执行在串行门控中消费；不启动多个 Uvicorn worker。Python 执行器复制干净系统解释器/标准库到临时 chroot，撤销附加组、降 UID/GID=65534、启用 no_new_privileges/seccomp，并限 CPU 2 秒、墙钟 5 秒、地址空间 256 MiB、输出 64 KiB。禁止 socket、fork/clone、mount、ptrace 等；不挂载宿主仓库、凭据或 /proc。

这提供受控 Python 工具的主机旁路限制，不是完整恶意内核代码隔离或任意外部 Agent 的沙箱。外部 MCP stdio 进程由管理员注册，是可信基础设施；元数据/响应不能授权，但不可信进程仍必须先由部署者独立隔离。默认不注册任何外部进程。真实网络模式需要显式域名 allowlist，DNS 公网校验、IP 固定、每跳检查和禁止跨来源重定向；开发演示使用本地收件账本。

Git push 固定到状态目录专属 bare 仓库，包含 GIT_PUSH + NET_EGRESS 两种 effect；HEAD/remote/branch 与审批绑定。commit 同时绑定工作区文件 stat 和 index 版本。文件 API 不能修改 .git 内部、凭据、符号链接或静态根外对象。

## 状态与隐私取舍

公共审计/导出先脱敏。为支持动作审批及 body_ref/content_ref 的精确数据引用，原始上下文、私有参数和 Memory 采用 Fernet 加密保存在本机，默认七天删除。密钥与密文同机，保护目标是降低数据库/导出单独泄露的风险，不能防御控制宿主 root 的攻击者。备份使用独立密钥加密，必须停服后制作一致快照，恢复到空目录；恢复启动后旧审批全部失效。

默认检测为规则，不依赖 GPU。可选本地 safetensors 模型接口尚未实测权重；配置后加载失败会关闭执行门控。CPU 性能报告只描述实际冻结输入和进程资源约束，不扩展为模型、外部网络或生产容量结论。

## 实现复查补充

审批绑定完整 Intent JSON 哈希，版本号遗漏更新也不能复用旧权限。自然语言合同模板包含明确的禁止读/写/提交/委派/记忆以及只读/离线约束，但仍不是通用语义解析模型。MCP inputSchema 不能通过远程 $ref 引起 HTTP 或本地文件检索；下游 stdio 原始 stderr 不落盘，SDK 日志和异常经过统一脱敏格式化。注册 server 本身仍属于可信计算基，此处理不赋予它执行不可信代码的资格。
