# ADR-010：先规划任务，再校验动作与数据来源

日期：2026-09-12；实测补充2026-09-13。状态：隔离候选，真实模型小样未通过。Owner：工程开发；独立评审未完成。

27B 正常任务配对的效用损失为25.77pp。28条基线成功但防护失败的任务中25条出现ASK，接收方和动态动作授权是主要原因。只按副作用授权太粗；ADR-009的字面合约也不能解释多步自然语言任务。

在 `artifacts/development/task-plan-v1` 实现任务规划候选。首次读取不可信工具结果前，仅向规划器提供原始任务、工具目录和操作员权限视图。计划含步骤、允许工具、参数约束、数据来源及调用次数上限。用户字面量必须给出原任务中的精确证据片段。模型语义判断属于显式信任假设，不能将它描述成形式化的用户意图证明。

执行时绑定任务、完整Intent、会话、包含server标识的工具目录和完整Action参数哈希；变异动作逐参数给出用户字面量或已允许工具观察的JSON指针/引文证明。有限Decimal运算可验证加减乘除和百分比，不使用eval或隐含舍入。SECRET或INJECTION_RISK来源不提供授权依据，失败/未执行观察不进入可信步骤状态。步骤配额预留并在成功后消耗；重复回报不重复消费。已有精确合约不能被规划器扩大。

规划只生成当前动作的临时精确授权，仍必须再次经过正常策略引擎。静态权限、明确禁止、秘密外发、凭据写入等硬限制继续生效；ASK没有自动批准路径。替代方案是自动批准常见ASK，但这无法证明动作与任务一致，因此未采用。完全确定的自然语言编译更易审计，但当前只覆盖ADR-009的有限语法。

候选238项pytest、20条黄金回归及6个固定模型/原生AgentDojo模拟工具链路夹具通过。真实27B小样已按当前v4批处理的完成状态排队，基线/防护各8例；只有小样实际结果产生后才评估质量和辅助模型延迟。[冻结清单](../evidence/task-plan-candidate.json)包含源码归档、测试和重复代码指纹。

当前只接入AgentDojo模拟运行器，尚无生产计划持久化、审批后恢复或原生Codex/Claude的完整工作流接入。不能用此候选的工程测试替代实际客户端验收。活动网关与当前v4源码保持原版本。
