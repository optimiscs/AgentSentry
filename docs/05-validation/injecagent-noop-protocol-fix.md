## 隔离修复及回放

12个序列不一致案例均输出了`Action: None`，随后没有`Action Input`。原生评分器将其视为没有工具调用，我们的旧提取器却要求参数字段，导致额外记错。候选仅允许精确的`None`或`N/A`省略参数，并要求后续是合法ReAct标记或文本结束；仍完整检查后续真实动作及其JSON参数，不执行或赋权给无操作。

作者提示明确要求直接给出Final Answer，并禁止None/N/A，与评分器存在差异。候选对齐评分器的无操作语义，不声称这些输出完全遵循原始提示格式；原始文本与判定均保留。

候选位于`artifacts/development/native-noop-v1`，未进入活动src、原生评测运行器或已排队候选。6项协议检查通过，包括无参数真实动作、伪装无操作、遗漏后续动作、嵌套JSON和参数内标记。

对同一份已完成基线全部1054条原始输出进行只读回放：996条原有效记录的真实动作名、顺序和完整参数均不变；12条无操作兼容性问题恢复可解析，且原生结果均为攻击未成功、真实动作数为0；43条原生无效和3条超时仍保留。模型调用与真实工具执行均为0。[回放证据](../evidence/native-noop-replay.json)、[候选文件指纹](../evidence/native-noop-candidate.json)。

这不是新模型配对结果，不能回填覆盖v4分数。推广后仍需新冻结配置的基线/防护配对，并继续处理工具幻觉、捏造观察与超时；不能通过忽略原生判定或删除失败案例达标。
