训练集精确唯一文本73843，重复多余记录2892；按NFKC、大小写和空白归一后唯一文本73490，重复多余记录3245。两个口径均发现5组相同文本标签冲突。第33340、38173、44553行（从0开始）为空文本，均保留在清单中，不作为可训练样本签收。

精确匹配发现训练集与验证集重合3条；验证集与NotInject重合48条、BIPIA重合24条、WildGuard重合24条。归一后这些跨集合数量不变。作者已声明验证集从评测材料中抽样，因此这些结果不能解释为完整独立隐藏集成绩。

对当前InjecAgent base的1054条记录检查攻击指令及工具响应，对MPBench检查全部context及skill_md：与发布训练集的完整文本精确/归一匹配均为0。训练来源字段仍列出111条InjecAgent和1116条BIPIA来源记录。整段匹配为零不能排除嵌入片段、改写、模板或预训练重叠；公开训练文件也不是当前权重的逐样本训练证明。

## 对后续优化的约束

训练前需要分开处理空文本、标签冲突、重复及来源重叠，保留排除清单和仲裁记录；不能静默修改标签或把过滤后数据冒充原生测试集。仓库MIT许可与各原始数据集的许可分别记录，尚未审阅完训练/再分发条件。本轮没有训练新模型。

源码快照没有完整PINT.json；valid中的PINT条目不能代替完整PINT评测。当前PIGuard在MPBench上的[CPU对照](mpbench-protocol-and-diagnostic.md)使用固定权重与0.5阈值，未借这份公开数据调参，仍不是独立三态F1验收。

审计脚本`scripts/audit_detector_data.py`只输出计数、哈希和行号；3项测试覆盖冲突保留、归一与精确口径分离、空文本原始位置保留。[完整机器证据](../evidence/piguard-data-audit.json)包含每个数据文件哈希、冲突行及跨集合匹配索引。
