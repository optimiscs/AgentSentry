首个目标版本为`v0.1.0-mvp`，尚未构建/发布。W7候选、W8正式交付日期为计划假设。发布包含代码、依赖锁、镜像/模型/策略manifest、迁移/回滚、验证结果、脱敏演示与已知限制，不只是一组页面截图。

## 渐进发布

| 阶段 | 环境和动作 | 进入/退出条件 |
|---|---|---|
| R0 离线验证 | 合成数据/模拟工具做shadow对照 | Schema、安全测试、20黄金全过，隐私/旁路/审批检查有证据 |
| R1 单受控Agent | enforce-critical，低风险其余动作记录 | 一条可信业务流程；硬拒绝始终有效；ASK超时不执行 |
| R2 精确审批 | 开启绑定对象的ASK | 变参/权限变化/重放/断连全部验证，误拦与ASK率在预算内 |
| R3 完整MVP策略 | 加入已通过的Memory/跨Agent等适用功能 | 全部适用P0/P1范围、公开效果和性能Gate签收 |
| R4 赛事交付 | 冻结版本、独立部署、录屏/现场演示 | 非作者从干净机器复现并验证回滚；最后封存test完成 |

Shadow仅用于允许风险的隔离测试；不能为减少误拦在真实敏感资源上停用Critical规则。模式变更记录操作者/理由/版本，回滚到已知安全配置，不直接切全局fail-open。

## 发布检查表（当前均未验收）

- [ ] 实际赛程、版本、Owner、支持入口/排除项已确认。
- [ ] RTM所有适用需求有实现和测试证据；没有未关闭S0/S1。
- [ ] Benchmark原生结果、三次重复、效用/ASK/错误率和SOTA出处完整。
- [ ] CPU-only和复杂路径SLO在明确配置下通过；连续稳定性观察完成。
- [ ] Compose干净部署、下游隔离、身份/Origin、日志脱敏和留存通过。
- [ ] 策略/模型/Schema/镜像版本固定；所有依赖/数据许可检查完成。
- [ ] 备份可恢复、迁移兼容、旧审批失效与回滚演练完成。
- [ ] Release Notes、演示脚本、已知限制及故障手册已核对。
- [ ] A发布检查、B安全策略、C评测签收均有实际日期/人名。

## 触发停止/回滚

任何敏感旁路、审批漂移或SECRET外发立即停止受影响高危路径并按事件响应处理；新版本造成效用损失>5pp或快速P95越界且持续到预设观察窗口，停止扩大范围并回到previous-known-good。不能在故障中临时放宽硬规则“救演示”。回滚详见22文档。

## 当前发布快照

已部署 5090 本地开发预览，浏览器通过 SSH 隧道连接。可运行接口、控制台、MCP 和工程回归已建立；正式 Release 的 Gate 仍关闭，参见 [测试报告](../05-validation/18-test-benchmark-report.md)。不启动公网暴露、企业上线或真实凭据迁移。Docker 文件已编写但本机无 daemon，不能勾选干净容器部署通过。
